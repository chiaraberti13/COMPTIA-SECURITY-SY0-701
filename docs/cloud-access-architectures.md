# SD-WAN, SASE, CASB, SWG e FWaaS

Le cinque categorie dell'obiettivo 3.2 sono ora voci autonome e ricercabili in
italiano e inglese. La precedente voce `ModernCloudNetArchitectures` conserva
l'ID per i dati salvati, ma è deprecata ed esclusa dall'interfaccia: glossario e
flashcard mostrano una sola definizione canonica per categoria.

| Voce | Ruolo principale | Non implica automaticamente |
| --- | --- | --- |
| SD-WAN | Connettività WAN e scelta del percorso | CASB, SWG o FWaaS |
| SASE | Architettura convergente rete + sicurezza | Ogni funzione citata in ogni offerta |
| CASB | Visibilità e policy per SaaS/cloud e dati | Filtraggio completo di tutto il Web |
| SWG | Controllo di URL, contenuti e traffico web | Governance API dei dati già nel SaaS |
| FWaaS | Firewall erogato da punti cloud | Intero catalogo SASE o tutte le funzioni NGFW |

L'implementazione deve essere valutata per capacità acquistate, modalità di
erogazione, punti di enforcement, policy e copertura dei flussi. Fonti primarie:
[Cisco, What Is SASE?](https://www.cisco.com/site/us/en/learn/topics/security/what-is-secure-access-service-edge-sase.html)
e [Microsoft Defender for Cloud Apps](https://learn.microsoft.com/en-us/defender-cloud-apps/what-is-defender-for-cloud-apps).
